# blog-assets-3
董達達 3C 私塾 圖床（第三代）。部落格 www.dada3c.tw 與 FB／IG／Threads 社群貼文的圖片，全走 GitHub + jsDelivr：

`https://cdn.jsdelivr.net/gh/dada3c/blog-assets-3@main/<英文slug>/<檔名>`

- 沿革：blog-assets（2.4GB，2026-10-19 被 jsDelivr 擋）→ blog-assets-2（工作樹 42MB，2026-11-04 逼近上限）→ 這個 repo（2026-11-04 起）。
- **jsDelivr 對單一 GitHub repo 有 50MB 上限**，超過會回 HTTP 403 `Package size exceeded`。
- 管理規則：工作樹（不含 .git）超過 40MB 就換下一棒（blog-assets-4）。量法：`du -sh --exclude=.git .`
- 舊 repo 不再推，舊文章網址維持原樣。
